## はじめに

CPG (Consumer Packaged Goods) プラットフォームは、メーカー、サプライヤー、ブランドをつなぎ、製品開発と生産を効率化するためのサービスです。本ガイドでは、以下の 2 つの利用方法を紹介します。

1. **アクティブ検索**: フィルターを使って製品やメーカーを検索
2. **パッシブマッチング**: プロジェクト要件を投稿し、最適なメーカー候補を受け取る

## スタートガイド

### 登録

1. ホームページで「サインアップ」をクリック
2. 名前、メールアドレス、パスワードを入力
3. 役割 (メーカー・ブランド・小売) を選択
4. 「アカウント作成」をクリック
5. 認証コードがメールで送信されます

### Google でログイン

1. ログインページで「Google で続行」をクリック
2. Google 認証ポップアップで権限を許可
3. 初回ログイン時はプロフィール設定へリダイレクト
4. 既存アカウントがある場合は自動ログイン

### メール認証

1. メールに届いた認証コードを確認
2. 6 桁のコードを入力
3. 「コードを再送」リンクで再送信可能
4. 認証完了後、プロフィール設定へ

## 方法 1: アクティブ検索

### 製品検索

1. メニューから「製品」を選択
2. 検索バーでキーワード検索
3. フィルターパネルで絞り込み
   - カテゴリー
   - 単位タイプ
   - フレーバープロファイル
   - 用途
   - メーカー
   - 原材料
   - 賞味期限
   - 包装サイズ

### メーカー検索

1. メニューから「メーカー」を選択
2. 検索バーでキーワード検索
3. フィルター項目
   - 業界
   - 所在地
   - 認証
   - 創業年

### フィルターと並べ替え

1. **並べ替え**
   - 名前 (A–Z / Z–A)
   - 関連度
   - 新着順
   - 価格 (安→高 / 高→安)
2. **ビュー切替**
   - グリッド / リスト
3. **高度なオプション**
   - サステナブル製品のみ
   - 特定の認証
   - 地域限定

### お気に入り

1. 製品・メーカーカードのハートアイコンをクリック
2. 「お気に入り」ページで一覧表示
3. 再度クリックで解除
4. 複数メーカーを比較リストに追加可能

## 方法 2: パッシブマッチング (プロジェクト投稿)

### ステップ 1: 製品カテゴリーの選択

1. 「プロジェクト投稿」セクションへ
2. 探しているサプライヤータイプを選択
   - メーカー (利用可能)
   - 包装サプライヤー (準備中)
   - 原材料サプライヤー (準備中)
3. 検索フィールドでカテゴリーを入力し選択
4. 「次へ」をクリック

### ステップ 2: プロジェクト定義

1. プロジェクト要件を説明
2. 生産量と単位を入力
3. プロジェクトステータスを選択
   - 調査段階
   - 生産準備完了
   - 発売済み
4. 包装タイプを選択
5. 希望製造場所を入力
6. 特別要件を追加
   - アレルゲン配慮
   - 必須認証
   - 追加メモ
7. プライバシー設定
8. 「次へ」をクリック

### ステップ 3: プロジェクト確認

1. 入力内容を確認
2. 必要に応じて修正
3. プロジェクトを送信
4. メーカー候補が見つかると通知されます

### プロジェクト管理

1. ダッシュボードでプロジェクト状況を追跡
2. 興味を示したメーカーを閲覧
3. プラットフォーム上でメーカーへ連絡
4. 必要に応じてプロジェクト詳細を更新
5. 完了したらプロジェクトを終了
